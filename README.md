# Lotex Clothing – B2B Wholesale ERP

**Location:** Kozhikode, Kerala  
**Hub:** Valiyangadi & Mavoor Rd  

Exact recreation of the Stitch design for the **Malabar Wholesale Sourcing & Distribution Hub**.

## Features

- Live inventory overview (Ready Stock, Active Bulk Runs, Pending Dispatch, Trade Credit)
- B2B Catalog & Bulk Lots table with filter
- Loom Mills Telemetry (Kannur, Tirupur, Calicut, Beypore, Malabar)
- ERP Quick Actions (Book Bulk Lot, Kerala E-Way Bill, Transfer Bale/Rolls, Yarn Spot Index)
- South India Cotton Index (MCX Cochin Spot)
- Fully responsive layout

## How to run

Just open `index.html` in any modern browser. No build step required.

## Tech

- Pure HTML + CSS + Vanilla JS
- Inter font
- Green-themed professional ERP UI matching the original Stitch design
